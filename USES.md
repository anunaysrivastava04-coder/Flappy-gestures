# Uses

- Play a Flappy Bird-inspired arcade game using webcam-based hand movement.
- Try keyboard movement when camera tracking is unavailable.
- Use touch dragging on compatible mobile/tablet devices.
- Demonstrate a browser-based computer-vision interaction using MediaPipe Tasks Vision.
- Explore a canvas-based game loop, collision checks, score tracking, responsive UI, and browser `localStorage`.

This is a browser game/demo. The supplied source does not include user accounts, online leaderboards, multiplayer, or a server-side database.
