# Programming Languages

## Used in the supplied source

- **HTML5** — page structure, screens, buttons, video, and canvas elements.
- **CSS** — layout, retro styling, responsiveness, and animation.
- **JavaScript (ES modules)** — game logic, hand-tracking integration, input handling, settings, sound, and rendering.

Tailwind utility classes are used in the HTML alongside custom CSS. Markdown files in this repository are documentation, not application programming languages.
